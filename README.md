# SILSILAI Hub v0.1 — ведущий общества + диспетчер моделей

Telegram-бот, который знает хребет проекта, говорит голосом и текстом на языке собеседника,
записывает идеи в общую память и сам выбирает, какой ИИ-модели отдать запрос: бесплатной, пока хватает лимита, платной — когда надо.

## Что внутри

| Файл | Что делает |
|---|---|
| `config/registry.yaml` | Реестр моделей: цена, бесплатный лимит, умения, стартовый балл. Правится без перезапуска. |
| `config/task_classes.yaml` | Классы задач: планка качества и потолок цены. Инвестор и приёмка — всегда платная модель. |
| `config/spine.md` | Хребет проекта (копия Notion). В запрос уходят только нужные куски. |
| `config/exam.yaml` | Эталонные вопросы для еженедельного экзамена. |
| `hub/router.py` | Диспетчер: выбор модели, квоты, бюджет, переключение при сбое за 3 с, журнал расхода. |
| `hub/brain.py` | Ведущий: промпт из хребта + истории, извлечение идей, дайджест. |
| `hub/bot.py` | Telegram: голос/текст, роли, приглашения, команды фаундера. |
| `hub/exam.py` | Экзамен моделей → баллы в реестр → система сама переключается на лучшую. |
| `data/hub.db` | Одна память: люди, разговоры, идеи, расход, баллы. SQLite. |

## Запуск (5 минут)

1. Создать бота у @BotFather → токен.
2. Узнать свой Telegram id (@userinfobot).
3. Получить ключи: **Groq** (бесплатный уровень, console.groq.com) и **Google AI Studio** (aistudio.google.com) — этого хватит на старт.
   Для инвесторских разговоров и дайджестов — ключ Anthropic (платный, потолок в `registry.yaml` → `budget_usd_per_month`).
4. `cp .env.example .env`, заполнить.
5. Сервер с Docker (VPS $5 или бесплатный Oracle):
   ```
   docker compose up -d --build
   ```
   Без Docker: `pip install -r requirements.txt && python -m hub.bot`

## Команды

- `/start` — знакомство. С `?start=<код>` — вход по приглашению (закрытый режим).
- `/invite` — своя ссылка-приглашение. Кто пришёл по ней, записан как приглашённый тобой.
- Голосовое сообщение — расшифровка + ответ.
- Фаундер: `/stats` — расход по моделям и классам за 30 дней; `/digest` — дайджест идей за неделю;
  `/role <id> founder|cofounder|companion|guest` — роли.

## Как работает выбор модели

1. Запрос получает класс (быстрые правила, иначе крошечный запрос к бесплатной модели).
2. Из реестра берутся модели с нужными умениями и баллом ≥ планки класса.
3. Бесплатные с остатком дневной квоты — первыми, затем платные по цене. При превышении месячного бюджета платные выпадают, кроме классов с `force_tier: paid`.
4. Не ответила за 3 с или вернула ошибку — следующая. До 4 попыток.
5. Каждый запрос — в журнал: кто, класс, модель, токены, цена, время.

## Экзамен (самообновление)

`python -m hub.exam` раз в неделю (в compose уже есть). Каждая модель отвечает на `exam.yaml`, судья ставит 0–100,
средний балл перезаписывает `quality` в реестре. Новая бесплатная модель набрала больше платной — диспетчер сам начнёт её использовать.
Добавить модель = одна запись в `registry.yaml`.

## Красные линии (зашиты)

- По одному аккаунту на провайдера. Никаких «десяти ключей ради лимитов».
- Через сторонний ИИ не ходят личные и платёжные данные — бот о них не спрашивает.
- Инвестору бот ничего не обещает и не договаривается — только рассказывает и передаёт фаундеру.
