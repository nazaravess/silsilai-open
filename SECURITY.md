# Безопасность

## Что где живёт
- **Этот репозиторий** — код Hub для совместной разработки. Секретов здесь нет и не будет.
- **Приватный репозиторий `silsilai`** — продакшен: скрипты установки и автообновления сервера,
  боевая конфигурация, внутренние документы. Доступ только у владельца.
- **Ключи и токены** — только у владельца (менеджер паролей / приватная страница ключей) и в `.env` на сервере.

## Почему подпись владельца обязательна
Код, принятый в продакшен, исполняется на боевом сервере с боевыми ключами.
Поэтому любой merge проходит через владельца, а в продакшен код попадает только после его решения.

## Сообщить об уязвимости или утечке
Напиши владельцу напрямую (не открывай публичный issue с деталями). Утёкший ключ считается скомпрометированным до перевыпуска.
