# Как вносить изменения в SILSILAI Hub

Здесь можно менять всё: любой модуль, тесты, реестр моделей. Правило одно:
**ничего не попадает в `main` без апрува владельца (@nazaravess).** Это его первая подпись.

## Путь изменения
1. Создай ветку от `main` (`feature/что-делаю`).
2. Внеси изменения, запусти `pip install -r requirements.txt pytest && pytest`.
3. Открой Pull Request, заполни шаблон.
4. CI проверит тесты и просканирует изменения на секреты. Красный CI — merge закрыт.
5. Владелец ревьюит и апрувит. После апрува merge может нажать любой участник с правом записи.
6. Новый коммит после апрува сбрасывает апрув: владелец смотрит финальный код.

## Что сюда нельзя
- Ключи, токены, пароли, приватные ключи, `.env`, базы данных (`data/*.db`).
- Личные id, IP-адреса серверов, скрытые URL, доступы.
- Скрипты установки и автообновления продакшен-сервера. Они лежат в приватном репозитории.

Если секрет попал в коммит: считай его скомпрометированным, сразу сообщи владельцу.
Он перевыпустит ключ. Удалить файл из истории мало, ключ всё равно надо менять.

## Секреты в разработке
Для локального запуска копируй `.env.example` в `.env` (он в `.gitignore`) и вводи свои тестовые ключи.
Чужие боевые ключи тебе не нужны и не выдаются.
